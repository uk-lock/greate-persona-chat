# S04 ペルソナ一覧画面

## 1. 概要

| 項目 | 内容 |
|---|---|
| 画面ID | S04 |
| 画面名 | ペルソナ一覧画面 |
| パス | `/personas` |
| 認証 | 必要 |

対応する画面一覧は [screen-list.md](../screen-list.md)、画面遷移は [screen-flow.md](../screen-flow.md) を参照。

## 2. 画面の目的

登録済みペルソナの一覧を閲覧し、任意のペルソナの詳細画面（S05）へ遷移する。

## 3. 想定ユーザー

ログイン済みの全ユーザー。ペルソナの閲覧のみが可能で、作成・編集はできない（[要件定義書](../requirements-definition.md) 6.2節）。

## 4. 表示内容

- ペルソナ名検索欄（部分一致でリアルタイム絞り込み）
- ペルソナ一覧（カード形式：肖像画像、名前、概要（最大50文字、超過分は省略））。登録ID順（作成順）に表示する。
- 検索結果0件時の案内文言
- 共通サイドバー（[screen-list.md](../screen-list.md) 3節）

## 5. UIコンポーネント

| コンポーネント | 種別 | 備考 |
|---|---|---|
| 検索入力欄 | text input | ペルソナ名の部分一致でリアルタイムに一覧を絞り込む（S01と同様、フロント側でのフィルタ。API呼び出しは行わない） |
| ペルソナカード | clickable card | 肖像画像＋名前＋概要（最大50文字。超過分は末尾に「…」を付けて省略）を表示。クリックでS05へ遷移する |

## 6. ユーザー操作

- 検索欄にペルソナ名を入力すると、一覧がリアルタイムに絞り込まれる。
- ペルソナカードをクリックすると、そのペルソナのS05画面へ遷移する。

## 7. バリデーション

検索欄・一覧ともに入力フォームを持たず、必須制約はない（検索欄が空欄の場合は全件を表示する）。

## 8. 状態遷移

- **読込中**：画面表示時、ペルソナ一覧取得中はローディング表示にする。
- **表示中**：取得したペルソナを登録ID順（昇順）に一覧表示する。
- **検索結果0件**：入力したキーワードに一致するペルソナがいない場合、「該当するペルソナが見つかりません」を表示する。
- **空データ**：ペルソナが1件も登録されていない場合、案内文言を表示する（通常運用では想定しない状態）。
- **エラー**：一覧取得に失敗した場合、エラーメッセージを表示する。

## 9. 画面遷移

- ペルソナカードのクリック → S05 ペルソナ詳細画面（`/personas/{persona_id}`）
- 共通サイドバーから他画面（新規チャット／チャット履歴／ペルソナ一覧／ログアウト）へいつでも遷移できる（[screen-list.md](../screen-list.md) 3節）。

## 10. APIとの入出力

対応API: [api.md](../api.md)

### ペルソナ一覧取得

```http
GET /personas
```

画面表示時に全件取得する。レスポンスは `id`昇順（登録順）で、ペルソナごとに `id`・`name`・`image_url`・`summary` を含む。ペルソナ名検索はフロント側で取得済みデータを絞り込む形で実現し、検索のたびにAPIを呼び出すことはしない。

フィールド名・ステータスコード等の詳細は実装時に確定し、[api.md](../api.md) との整合を取ること。

## 11. 権限制御

ログイン必須画面。未ログイン状態でアクセスした場合はS00へリダイレクトする。閲覧のみで、ペルソナの作成・編集操作は提供しない（[要件定義書](../requirements-definition.md) 6.2節）。

## 12. その他実装上の注意事項

- 概要（`summary`）の表示は最大50文字とし、超過分は末尾に省略記号「…」を付けて省略する。全文はS05 ペルソナ詳細画面で確認する。
- ペルソナ名検索は、要件定義書6.2節の更新によりS01・S04共通の対象範囲となった（[requirements-definition.md](../requirements-definition.md)）。国・年代等の複合条件による絞り込みは引き続き対象外。
- MVPでは一覧を全件取得・表示する方針とし、ページングや無限スクロールは対象外とする（S01と同様の方針）。
