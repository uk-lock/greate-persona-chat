# 画面遷移図

対応する画面一覧は [screen-list.md](./screen-list.md) を参照。

## 1. 主要フロー

ログイン後の主要な画面遷移（業務フロー）を示す。共通サイドバーからの遷移は「2. 共通サイドバー遷移」に別途示す。

```mermaid
flowchart TD
    S00["S00 ログイン画面"]
    S01["S01 新規チャット画面"]
    S02["S02 チャット履歴画面"]
    S03["S03 チャット画面"]
    S04["S04 ペルソナ一覧画面"]
    S05["S05 ペルソナ詳細画面"]

    S00 -->|ログイン成功| S02
    S02 -->|Open| S03
    S01 -->|チャット開始| S03
    S04 -->|ペルソナ選択| S05
    S05 -->|チャット開始\n対象ペルソナ選択済み| S01
```

## 2. 共通サイドバー遷移

S01〜S05 のログイン後の全画面には共通サイドバーが表示され、以下の4項目へいつでも遷移できる。

```mermaid
flowchart LR
    Sidebar(("共通サイドバー\n（S01〜S05のいずれからでも）"))
    Sidebar -->|新規チャット| S01["S01 新規チャット画面"]
    Sidebar -->|チャット履歴| S02["S02 チャット履歴画面"]
    Sidebar -->|ペルソナ一覧| S04["S04 ペルソナ一覧画面"]
    Sidebar -->|ログアウト| S00["S00 ログイン画面"]
```

## 3. チャット画面（S03）内の状態遷移

チャット画面はページ遷移ではなく、画面内の状態（生成中／待機中）で振る舞いが変わる。会話進行モデルの詳細は [api.md](./api.md) の「メッセージ送信（会話進行トリガー）」を参照。

`chat_mode` はチャット作成時に固定され、以後変わらないため、`USER_PARTICIPATED` と `PERSONA_ONLY` は状態遷移としても別物である。混在させず、モードごとに図を分ける。

### 3.1 USER_PARTICIPATED モード

「入力待ち」＝ユーザーが自由にメッセージを送信できる状態（送信ボタン有効）。

```mermaid
stateDiagram-v2
    [*] --> 入力待ち

    入力待ち --> ペルソナ応答生成中 : ユーザーがメッセージ送信
    ペルソナ応答生成中 --> ペルソナ応答生成中 : 連鎖継続（上限まで）
    ペルソナ応答生成中 --> 入力待ち : 応答完了（連鎖の有無を問わない）
    ペルソナ応答生成中 --> 入力待ち : ユーザーが停止（stop）
```

### 3.2 PERSONA_ONLY モード

「停止中」＝未開始または自動進行が止まっている状態（開始ボタンが表示されている）。

```mermaid
stateDiagram-v2
    [*] --> 停止中

    停止中 --> 自動進行中 : ユーザーが開始（start）
    自動進行中 --> 自動進行中 : 連続生成
    自動進行中 --> 停止中 : ユーザーが停止（stop）
```
