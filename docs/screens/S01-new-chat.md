# S01 新規チャット画面

## 1. 概要

| 項目 | 内容 |
|---|---|
| 画面ID | S01 |
| 画面名 | 新規チャット画面 |
| パス | `/chats/new` |
| 認証 | 必要 |

対応する画面一覧は [screen-list.md](../screen-list.md)、画面遷移は [screen-flow.md](../screen-flow.md) を参照。

## 2. 画面の目的

ペルソナを設定値で定めた下限〜上限の範囲で選択し、チャットモードを選んだうえで新規チャットを開始する。

## 3. 想定ユーザー

ログイン済みの全ユーザー。

## 4. 表示内容

画面は上下2つのゾーンで構成する。

- **選択済みペルソナ一覧（上部）**：選択中のペルソナを名前＋×マークで表示する。×マーク押下で選択を解除できる。
- **ペルソナ名検索欄**：ペルソナ名で部分一致検索できる。
- **選択可能なペルソナ一覧（下部）**：全ペルソナを肖像画像＋名前で一覧表示する。検索キーワードで絞り込まれる。選択済みのペルソナもここに残り続け、チェックマーク等で選択中と分かる表示にする。
- 選択状態の表示（例：「（選択数）/（上限）体選択中」）
- チャットモード選択（`USER_PARTICIPATED` / `PERSONA_ONLY`）
- 「チャット開始」ボタン
- 共通サイドバー（[screen-list.md](../screen-list.md) 3節）

S05 ペルソナ詳細画面から「チャットを始める」等の導線で遷移してきた場合は、対象ペルソナが選択済み状態で表示される。

## 5. UIコンポーネント

| コンポーネント | 種別 | 備考 |
|---|---|---|
| 検索入力欄 | text input | ペルソナ名の部分一致でリアルタイムに下部一覧を絞り込む（フロント側でのフィルタ。API呼び出しは行わない） |
| 選択済みペルソナ一覧 | selected item list | 選択中のペルソナを名前＋×マークで表示。×マーク押下で選択解除（一覧から除外） |
| 選択可能なペルソナ一覧 | selectable card list | 全ペルソナを肖像画像＋名前で表示。検索欄の入力で絞り込まれる。選択済みのカードはチェックマーク・枠線等で選択中と分かる表示にする。クリックで選択／選択解除 |
| 選択数表示 | テキスト | 例：「（選択数）/（上限）体選択中」 |
| チャットモード選択 | radio | `USER_PARTICIPATED` / `PERSONA_ONLY`。初期値は `USER_PARTICIPATED` |
| チャット開始ボタン | button | 選択数が下限〜上限の範囲外の間は無効化。送信中はローディング表示＋無効化 |

## 6. ユーザー操作

- 検索欄にペルソナ名を入力すると、下部の「選択可能なペルソナ一覧」がリアルタイムに絞り込まれる。
- 下部の「選択可能なペルソナ一覧」からペルソナカードをクリックすると選択済みになり、上部の「選択済みペルソナ一覧」に追加される（下部一覧からは消えず、選択中の表示に切り替わる）。
- 上部の「選択済みペルソナ一覧」の×マークを押下すると選択が解除され、上部一覧から除外される（下部一覧では通常表示に戻る）。
- チャットモードをラジオボタンで選択する。
- 「チャット開始」ボタンを押下してチャットを作成する。

## 7. バリデーション

| 項目 | ルール |
|---|---|
| ペルソナ選択数 | 設定値による下限〜上限（[要件定義書](../requirements-definition.md) 6.3節） |
| チャットモード | 必須（ラジオボタンのため常にいずれかが選択された状態） |

- 選択数が上限に達した場合、未選択のペルソナカードはグレーアウトして選択不可にする（下部一覧・検索結果の両方に適用）。
- 選択数が下限未満の間は「チャット開始」ボタンを無効化する。
- **下限・上限の数値は今後変更される可能性があるため、フロント・バックエンドともにマジックナンバーではなく設定値（定数）として扱うこと。**
- バックエンド側でも同様の範囲チェックを行う（[api.md](../api.md) 参照）。
- 検索欄自体には必須制約はない（空欄の場合は全件を表示する）。

## 8. 状態遷移

- **初期表示**：ペルソナ一覧を読み込んで表示する。検索欄は空。S05から遷移した場合は対象ペルソナが選択済み状態、それ以外は0体選択の状態から開始する。選択数が下限未満のため、開始ボタンは非活性。
- **選択中**：選択数が下限〜上限の範囲内であれば開始ボタンが活性、範囲外であれば非活性になる。
- **検索結果0件**：入力したキーワードに一致するペルソナがいない場合、下部一覧に「該当するペルソナが見つかりません」を表示する。選択済み一覧や開始ボタンの状態には影響しない。
- **送信中**：開始ボタンをローディング表示にし、ペルソナ選択・モード選択・開始ボタンを操作不可にする（二重送信防止）。
- **エラー**：チャット作成APIが失敗した場合、エラーメッセージを表示し、選択状態を保持したまま操作可能な状態に戻す。
- **空データ**：ペルソナ一覧が0件の場合、「選択可能なペルソナがありません」等のメッセージを表示し、開始ボタンは常に無効化する（通常運用では想定しない状態）。

## 9. 画面遷移

- チャット作成成功 → S03 チャット画面（`/chats/{chat_id}`）
- S05 ペルソナ詳細画面から遷移してきた場合、対象ペルソナが選択済み状態で表示される。
- 共通サイドバーから他画面（新規チャット／チャット履歴／ペルソナ一覧／ログアウト）へいつでも遷移できる（[screen-list.md](../screen-list.md) 3節）。この場合、選択中の状態は破棄される想定。

## 10. APIとの入出力

対応API: [api.md](../api.md)

### ペルソナ一覧取得

```http
GET /personas
```

画面表示時に選択候補のペルソナ一覧を全件取得する。ペルソナ名検索はフロント側で取得済みデータを絞り込む形で実現し、検索のたびにAPIを呼び出すことはしない。

### チャット作成

```http
POST /chats
```

リクエスト:

```json
{
  "persona_ids": [1, 2],
  "chat_mode": "USER_PARTICIPATED"
}
```

レスポンス（想定）:

- 成功時（201）：作成されたチャット情報（`chat_id` 等）を返す。フロントは `chat_id` を用いてS03へ遷移する。`title` は固定文言（例：「新規チャット」）で作成され、会話内容をもとにしたタイトル自動生成は別途非同期に行われる（[db.md](../db.md) `t_chat` 参照）。
- 失敗時（400）：`persona_ids` の件数が範囲外の場合など、バリデーションエラー時に返す。

フィールド名・ステータスコード等の詳細は実装時に確定し、[api.md](../api.md) との整合を取ること。

## 11. 権限制御

ログイン必須画面。未ログイン状態でアクセスした場合はS00へリダイレクトする。

## 12. その他実装上の注意事項

- ペルソナカードの肖像画像表示のため、`m_persona.image_url` を使用する（[db.md](../db.md) 参照）。`image_url` が未設定の場合はデフォルトのプレースホルダー画像を表示する。
- ペルソナ選択数の下限・上限は設定値として扱い、将来的な変更（例：上限を6体にする等）に備える。
- ペルソナ名検索は、要件定義書6.2節の更新により対象範囲となった（[requirements-definition.md](../requirements-definition.md)）。国・年代等の複合条件による絞り込みは引き続き対象外。
- S04 ペルソナ一覧画面にも同様のペルソナ名検索を設ける想定（S04の画面定義時に詳細を確定する）。
