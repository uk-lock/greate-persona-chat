# S05 ペルソナ詳細画面

## 1. 概要

| 項目 | 内容 |
|---|---|
| 画面ID | S05 |
| 画面名 | ペルソナ詳細画面 |
| パス | `/personas/{persona_id}` |
| 認証 | 必要 |

対応する画面一覧は [screen-list.md](../screen-list.md)、画面遷移は [screen-flow.md](../screen-flow.md) を参照。

## 2. 画面の目的

指定したペルソナの詳細プロフィールを表示する。あわせて、そのペルソナを選択済みの状態で新規チャット画面（S01）へ遷移できるようにする。

## 3. 想定ユーザー

ログイン済みの全ユーザー。ペルソナの閲覧のみが可能（[要件定義書](../requirements-definition.md) 6.2節）。

## 4. 表示内容

- ページ上部固定の「チャットを始める」ボタン
- 肖像画像
- 名前・国・年代
- 概要（全文表示。S04のような省略はしない）
- 詳細説明
- 性格
- 経歴
- 発言例（引用符形式で縦に並べる）
- 「一覧に戻る」導線（S04へ）
- 共通サイドバー（[screen-list.md](../screen-list.md) 3節）

## 5. UIコンポーネント

| コンポーネント | 種別 | 備考 |
|---|---|---|
| チャットを始めるボタン | button（上部固定） | クリックで、対象ペルソナを選択済みの状態にしてS01へ遷移する |
| 肖像画像 | image | `image_url` が未設定の場合はデフォルトのプレースホルダー画像を表示する |
| 基本情報 | テキスト | 名前・国・年代 |
| 概要／詳細説明／性格／経歴 | テキスト | `m_persona` の該当項目をそのまま表示 |
| 発言例一覧 | quote list | 引用符形式で縦に並べる。`sample_quotes` が空またはNULLの場合はセクション自体を表示しない |
| 一覧に戻るリンク | link | クリックでS04へ遷移する |

## 6. ユーザー操作

- 「チャットを始める」ボタンを押すと、対象ペルソナが選択済みの状態でS01 新規チャット画面へ遷移する。
- 「一覧に戻る」リンクを押すと、S04 ペルソナ一覧画面へ遷移する。

## 7. バリデーション

本画面は閲覧専用で入力フォームを持たないため、バリデーションはない。

## 8. 状態遷移

- **読込中**：画面表示時、ペルソナ詳細情報の取得中はローディング表示にする。
- **表示中**：取得したペルソナ情報を表示する。
- **Not Found**：`persona_id` が存在しない、または削除済み（API 404）の場合、エラー画面は表示せずS04 ペルソナ一覧画面へ自動的にリダイレクトする。
- **エラー**：404以外の通信エラー（500等）が発生した場合は、自動リダイレクトはせずエラーメッセージを表示する。

## 9. 画面遷移

- 「チャットを始める」ボタン → S01 新規チャット画面（対象ペルソナ選択済み状態）
- 「一覧に戻る」リンク → S04 ペルソナ一覧画面
- `persona_id` が存在しない／削除済みの場合 → S04 ペルソナ一覧画面へ自動リダイレクト
- S04 ペルソナ一覧画面でのカード選択から本画面へ遷移する（[screen-flow.md](../screen-flow.md) 参照）。
- 共通サイドバーから他画面（新規チャット／チャット履歴／ペルソナ一覧／ログアウト）へいつでも遷移できる（[screen-list.md](../screen-list.md) 3節）。

## 10. APIとの入出力

対応API: [api.md](../api.md)

### ペルソナ詳細取得

```http
GET /personas/{persona_id}
```

画面表示時に取得する。レスポンスには `m_persona` の全項目（`id`・`name`・`image_url`・`country`・`era`・`summary`・`description`・`personality`・`biography`・`sample_quotes`）を含む。対象が存在しない、または削除済みの場合は404を返す（8節・9節参照）。

フィールド名・ステータスコード等の詳細は実装時に確定し、[api.md](../api.md) との整合を取ること。

## 11. 権限制御

ログイン必須画面。未ログイン状態でアクセスした場合はS00へリダイレクトする。閲覧のみで、編集操作は提供しない（[要件定義書](../requirements-definition.md) 6.2節）。

## 12. その他実装上の注意事項

- `sample_quotes` が空配列またはNULLの場合、発言例セクション自体を非表示にする（[db.md](../db.md) `m_persona` 参照）。
- S01への遷移時、対象ペルソナを事前選択済みの状態にする実装方法（遷移パラメータや状態管理の方式）は実装時に確定する。S01側の仕様は [S01-new-chat.md](./S01-new-chat.md) を参照。
