# Inspect

安全に変更するために必要な最小限の前提を確認する。

1. 依頼内容を読み、対象の動作や対象ファイルを特定する
2. 関連するソース・設定・ドキュメントを読み、前提を把握する（対象ファイルの種類に応じて `docs/coding/` の規約も確認する：共通は `common.md`、Pythonは `backend-python.md`、TypeScript/Reactは `frontend-typescript-react.md`、API境界に関わる場合は `api-contract.md`。関係しないものは読まない）
3. 主な依存関係・副作用・影響を受けるモジュールを整理する
4. 影響範囲・未解決事項・仮定を要約する
5. 結果を簡潔にして、次の計画や実装に渡せる形にする

出力形式:

- 対象スコープ
- 関係する主要ファイルと設定
- 依存関係や副作用
- 未解決事項
- 次の推奨アクション

コードは変更しない。事実と仮定を分けて整理する。
