# Plan

作業を安全に進めるために、順序立てて分解する。

1. 目標と完了条件を要約する
2. スコープとスコープ外を明確にする
3. 独立して検証できる小さな手順に分ける
4. 依存関係とリスクの順に並べる
5. 前提や確認が必要な点を残す

出力形式:

- 目標
- スコープ
- 依存関係
- 計画した手順
- 完了条件

アーキテクチャを決めたり、実装の詳細を書いたりしないでください。計画は簡潔でレビューしやすい形にする。
