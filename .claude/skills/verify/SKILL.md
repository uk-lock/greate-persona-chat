# Verify

変更内容を明示された期待値に照らして確認する。

1. 変更したファイルと周辺コンテキストを確認する
2. 目的・要件・制約と照合する
3. テスト不足・回帰・曖昧な挙動を明示する
4. 問題を解決するために必要な最小の次アクションを提案する
5. 出力は簡潔で具体的、根拠ベースにする

出力形式:

- 対象変更
- 確認した内容
- 問題点やリスク
- 推奨する次の対応

新しい動作を実装したり、根拠なく判断を補強したりしないでください。ギャップは明確に示す。
